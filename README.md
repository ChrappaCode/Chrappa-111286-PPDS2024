# Zadanie 01 

Táto vetva obsahuje zdrojové kódy ku **zadaniu 1** z PPDS.

Úlohou zadania je vyriešenie problému "**kto jedol prvý**". V zadaní sme vytvorili dve vlákna reprezentujúce `Jana` a `Fera`.

Problém "**kto jedol prvý**" spočíva v tom, že simulujeme bežné úkony tj. *spánok*, *ranná hygiena*, *telefonát* a *raňajkovanie*. Hlavnou premisou zadania je zabezpečenie aby `Jano` raňajkoval skôr ako `Fero`, tj. aby vlákno 1 vykonal tento úkon skôr ako vlákno 2.
